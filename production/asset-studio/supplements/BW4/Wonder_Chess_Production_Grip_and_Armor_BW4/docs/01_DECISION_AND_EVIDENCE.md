# 01 — Why this is a fixed game-hand task

## Findings from the supplied BW3 report

BW3 is an approach study, with the other fingers open, not a closed hand. The retained glove cleared the recorded self/ideal-handle queries, but the body web folded and the glove intersected the body. Thumb pads remained approximately 27.59–31.64 mm from the fixture, facing away. The report states that no mesh, rest-surface, weight, shape-key or rest-rig reconstruction occurred: the experiment changed the trajectory and joint-flexion distribution.

The measured clearance is useful evidence that the path changed. It is not evidence that the web was rebuilt or a useful grip was obtained. The attached screenshot visibly shows a narrow folded web; the report supplies the evaluated crossing results. The precise cause cannot be assigned to one vertex from the screenshot alone.

Most important for production: BW3 section “Stop and next decision” reports a read-only inspection of the current 27-bone game rig, no digit bones, and seven actions that keep hand/equipment rigid relative to the hand across 865 sampled half-frames. The same report warns that the actual sword differs from the diagnostic cylinder. The underlying source audit itself is not attached here; Codex must read it locally and check whether current source supersedes it.

See [supplied report](../evidence/BW3_REVIEW_supplied.md), especially its lines 15, 39–49 and 65–71, and [supplied verification](../evidence/BW3_VERIFICATION_supplied.json).

## New production interpretation — proposed, not a retroactive pass

The game task is: **an attractive closed gloved hand which stays correctly fitted through its actual required animation range.** The research task is: **a continuously opening/closing, collision-aware anatomically driven hand suitable for reuse on diverse bodies and handles.** These have different output contracts.

Do not keep the game's armor work dependent on completing the second problem when the first is the actual requirement. Equally, do not label the fixed solution as a repaired animated grasp.

Changes to the actual output representation must be declared. This proposal permits a permanently gloved derived export to omit fully covered underlying skin, but not source deletion or a fake body-deformation pass. It does not permit disguising a defective glove with armor or hiding visible wrist gaps.

## Exit decision

A local technical reviewer may identify a hand as structurally ready for in-game review. A visual reviewer may report that it is a credible fixed-hand candidate. Neither fabricates Pram's approval. Runtime checks and a reviewed canonical promotion are separate.

Do not target an arbitrary “near-perfect” score. Test clearly stated uses: gameplay, gallery, the existing seven clips and actual costume clearances. Keep research limitations in the record.

## Effort allocation

This next assignment should predominantly produce changed geometry and visible assembly tests. Preflight should reuse known tools and target only potentially affected preservation checks. Full inherited files can be checked at intake and delivery, not rebuilt into a new verification framework.

An initial blocked grip does not authorize burying the hand task, but it also does not block independent breastplate/shoulder design. Each output retains its own truthful status.
