# Wonder Chess — Production Grip and Armor BW4

**Proposed next assignment: make Ada's actual fixed game grip, then produce a convincing armor assembly.**

This package makes a scoped production decision. It is not another attempt to complete the general animated-hand experiment. Sending `FIRST_MESSAGE_TO_CODEX.md` adopts an isolated fixed-grip candidate trial; it does not issue artistic approval, authorize a canonical source replacement, or reclassify BW3 as passed.

## Start

1. Place this folder under the existing repository, for example `production/asset-studio/supplements/BW4/`.
2. Keep the folder structure. Do not extract a replacement repository, overwrite `AGENTS.md`, or install a new skill framework.
3. Give Codex [FIRST_MESSAGE_TO_CODEX.md](FIRST_MESSAGE_TO_CODEX.md).
4. Work from the current local sources after a short preflight. Preserve frozen BW1–BW3 and the running game.

## Deliverable sequence

- **H1:** one intentionally constructed closed right glove, fitted to the real sword.
- **H2:** wrist integration and the seven actual game clips, first in a runtime-rig candidate, then isolated Unreal review where tools exist.
- **A1:** gauntlet/cuff-to-bracer refinement after H1 is structurally credible.
- **A2:** an attractive breastplate/backplate and one shoulder/sleeve assembly. Chest blockout may proceed independently if hand integration is blocked.
- **A3:** materials and small detail only after the major shapes and movement work.

## Boundaries

No finished `.blend`, new model, plugin, solver, neural training or Unreal import is included. All future acceptance states start NOT_RUN. These procedures are proposed engineering/art direction, not guaranteed output quality.

Historical reports remain failed. Protect original indexed MPFB data, keys, animation banks, shared skeleton and existing game. Derived export geometry can be different, with a declared scope and rollback.

The reference navigator's museum images require internet. No third-party image files or meshes were bundled: direct image downloads were unavailable in this session. The supplied concept and failure image are included locally, unchanged except for separately identified native crops. Some research pages were available only through indexed descriptions; the registry says which.
