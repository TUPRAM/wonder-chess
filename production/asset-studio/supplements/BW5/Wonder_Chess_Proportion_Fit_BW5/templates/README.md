# Small records only

These JSON templates are incomplete and unexecuted. Fill them from the actual source. `null` means unknown/not measured, never zero or passed. Keep their named units and provenance. Do not spend the art run building a schema platform around them.

The section record links the actual body/padding/plate layers in one frame. The hand record declares the selected hilt and the occupied keep-out region before root construction. Both preserve separate visual, geometric, motion and approval status.
