# AS1 skill index

All procedures are authored files. Discovery and actual tool execution must be verified in the installed Codex environment.

| Skill | Purpose | Primary manual |
|---|---|---|
| `$wca-orchestrate` | Route new or revised Wonder Chess assets through AS1; do not redesign gameplay. | `00_SYSTEM.md` |
| `$wca-brief` | Define scope, identity, parts, budgets and provenance before creating asset references. | `01_CONCEPT_AND_REFERENCES.md` |
| `$wca-concept` | Author or generate identity-locked concept and detail images for an asset; not final mesh evidence. | `01_CONCEPT_AND_REFERENCES.md` |
| `$wca-reference` | Reconcile AI views into a measured construction pack and set up Blender references. | `01_CONCEPT_AND_REFERENCES.md` |
| `$wca-blockout` | Build or revise only the large forms and silhouette of an approved asset reference. | `02_MODELING_AND_LIKENESS.md` |
| `$wca-organic` | Refine organic anatomy, face, hands or creature forms; not a whole-character one-shot generator. | `02_MODELING_AND_LIKENESS.md` |
| `$wca-hard-surface` | Construct armor, weapons and rigid props with deliberate cross-sections and attachment. | `02_MODELING_AND_LIKENESS.md` |
| `$wca-costume` | Build character clothing, layered armor undergarments, hair masses and accessories. | `02_MODELING_AND_LIKENESS.md` |
| `$wca-review` | Critique actual asset images or motion against approved references; never self-issue human approval. | `06_REVIEW_AND_OPERATIONS.md` |
| `$wca-retopo` | Build or validate motion-ready/runtime topology from approved forms. | `03_TOPOLOGY_UV_BAKING.md` |
| `$wca-uv-bake` | Unwrap, plan texture density and bake approved source detail onto runtime geometry. | `03_TOPOLOGY_UV_BAKING.md` |
| `$wca-material` | Author coherent stylized materials and textures without using them to hide form errors. | `03_TOPOLOGY_UV_BAKING.md` |
| `$wca-rig` | Build a versioned authoring rig and explicit game export skeleton. | `04_RIG_SKIN_MOTION.md` |
| `$wca-skin` | Initialize, correct and verify deform weights and actual joint motion. | `04_RIG_SKIN_MOTION.md` |
| `$wca-motion` | Author and review complete hero or effect motion with authoritative event timing preserved. | `04_RIG_SKIN_MOTION.md` |
| `$wca-optimize` | Create and validate distance/platform representations without destroying approved identity. | `05_UNREAL_AND_RELEASE.md` |
| `$wca-unreal` | Import and verify approved assets in the actual Unreal project and packaged runtime. | `05_UNREAL_AND_RELEASE.md` |
| `$wca-environment` | Produce modular arena/environment/foliage assets with assembly and scene readability checks. | `08_ASSET_CLASS_ROUTES.md` |
| `$wca-vfx` | Design readable skill effects and timing in Unreal; not new combat mechanics. | `08_ASSET_CLASS_ROUTES.md` |
| `$wca-ui` | Produce game icons, portraits and interface art with small-size and state validation. | `08_ASSET_CLASS_ROUTES.md` |
| `$wca-audio` | Create or integrate game sound assets with provenance, listening and in-context mix tests. | `08_ASSET_CLASS_ROUTES.md` |
| `$wca-release` | Prepare final asset promotion after current technical and human acceptance; do not publish automatically. | `05_UNREAL_AND_RELEASE.md` |
