## Main recommendation
Change the editable representation: a small deliberate control cage for orbital anatomy and a broad shaped hair volume with explicit root/underside decisions. More source samples are not the missing proof. This does not imply all procedural work is unsuitable; it means the last representation did not provide effective artistic control over these regions.

## Freeze versus replace
Preserve the current source file, approved reference identity, torso/armor/collar/neck context, correct overall measurements and camera baselines. Allow deliberate replacement of the defective eye-region construction and hair geometry inside an isolated candidate. If the head shell cannot accept the improved region without artifacts, create a separate rebuilt frontal-shell candidate; do not be trapped by vertex identity in an unrigged study.

Keep hidden failed objects in a clearly excluded diagnostics collection or a separate archive copy. Use an explicit render collection and list its objects. No full-scene export is authorized.

The anatomical-side marker found in the upload is `ANATOMICAL_RIGHT_POS_X`; another marker is `FORWARD_POS_Y`. Confirm their actual relation to the current local scene before choosing a side or mirroring. Do not infer anatomy from left/right on screen alone.
