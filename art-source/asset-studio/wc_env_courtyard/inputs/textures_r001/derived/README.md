# Derived wall texture

`wall_stone_tile.png` is cut from `../../references/wall_section_r001/main.png` (pixels 330,312 to 925,1037: seven whole
courses of masonry), mirrored left-to-right so it repeats horizontally, and resized to 2048x1024. One repeat covers about
10.0 m by 6.1 m of wall. It is the fallback named in `production/environment/courtyard/BRIEFS.md`: the wall section never
got a usable four-view set, so the simple wall shapes in the game carry this texture instead. Candidate only; not approved.
