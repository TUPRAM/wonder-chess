# Blender helpers: execution status and use

These are **authored, Python-syntax-checked scaffolds**, not Blender-tested scripts. No character mesh or animation is generated by this kit. They assist the local Codex implementation; the detailed hero briefs remain the actual production task.

Use an installed Blender binary, verify the CLI options against its version, and use `--python-exit-code 1` so a Python exception produces a failed batch run. Quoted absolute paths are safest. `--factory-startup` is for the separate calibration process, not a permission to reset a user's open project.

```powershell
& $env:BLENDER_EXE --background --factory-startup --python-exit-code 1 --python tools/blender/create_calibration_scene.py -- --output "$PWD/art-source/calibration/WC_Calibration.blend"
& $env:BLENDER_EXE "C:/absolute/path/hero.blend" --background --python-exit-code 1 --python tools/blender/inspect_scene.py -- --collection EXPORT --output "$PWD/reports/hero-inspection.json" --require-skin
& $env:BLENDER_EXE "C:/absolute/path/hero.blend" --background --python-exit-code 1 --python tools/blender/export_collection.py -- --collection EXPORT --output "$PWD/exports/hero.fbx" --profile tools/blender/profiles/fbx_candidate.json --acknowledge-unverified-profile
```

The third example acknowledges an **unverified** profile for a calibration experiment. Do not use that switch as a substitute for measurement. After proving source units, forward arrow, root scale, animation, normals, and actual Unreal import/reimport, save a separate named/versioned calibrated profile with an evidence reference. Do not merely edit its status to suppress the warning.

The included profile exports only the current action and scene frame range. Select/assign the intended action explicitly in a per-hero script and export one named animation at a time. Current Blender action-slot behavior must be checked in the installed version. Do not turn on “all actions” and treat the resulting clip names as intentional.

Structural inspection is deliberately incomplete: review UV intent, deformation, appearance, animation and gameplay-camera readability manually/in screenshots. Material count is per mesh; also inspect final imported per-hero draw-call/material totals. For socket props use a separate inspection run rather than falsely requiring an armature modifier. Set a higher triangle budget for an entire arena collection only when documented.
