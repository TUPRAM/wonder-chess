# Character art review

Use this when editing character shape, materials, or presentation—not for unrelated gameplay work.

1. Read the active AQ1 art brief, current unit record, current asset manifest, and existing repository instructions. Confirm revision and exclusive `.blend` ownership.
2. Save/hash a before-copy. Inspect matched clay/material views and actual board-camera framing. List the three largest visible defects.
3. Define a bounded edit against named semantic parts. Do not select topology by obsolete component counts or silently reconstruct the canonical model.
4. Execute through permitted Blender tooling. Inspect actual returned images; report what changed visually. Fix primary forms before decorations.
5. Preserve technical interfaces and test deformation. Rig/proportion incompatibility needs a versioned candidate migration, not a silent global edit.
6. Keep human art approval separate from structural/export success. Unreal captures and reimport are required for final acceptance.
7. Stop bulk rollout until the reference is approved. Record real evidence and unresolved checks; never fabricate images, measured results, or approvals.

Do not bypass safe mode, overwrite another lane, upload private assets, install paid tools, or publish without authorization. A tool timeout requires state inspection before retrying.
