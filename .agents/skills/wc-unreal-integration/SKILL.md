# wc-unreal-integration

1. Read `docs/UNREAL_IMPLEMENTATION.md`, current task card and canonical data contract.
2. Verify installed editor/compiler/SDK and existing genuine Wonder Chess project; never migrate VEILMARK.
3. Implement in owned C++/Blueprint/content paths. Python is editor tooling only.
4. Compile, import and run relevant engine tests; validate actual integer rows and asset references.
5. Package early and inspect a real launch. Eight bots in one process are not proof of multiplayer.
6. Report real commands/logs/evidence; a missing editor blocks engine verification rather than authorizing a web substitute.

Never overwrite another lane’s binaries, expose secrets, install untrusted helpers, make purchases, or publish without authorization. Maintain explicit rollback and execution evidence.
