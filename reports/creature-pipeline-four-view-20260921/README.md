# Four-view workflow amendment — 21 September 2026

**Status: documentation updated to pipeline 1.1; no production trial performed.**

The owner requested the four-image Meshy interface shown in
[their screenshot](meshy-four-view-ui.png). New creature geometry now defaults to
one Main/front, anatomical Left, Back and anatomical Right set. This is one
multi-view model job, not four single-image jobs. Already accepted models retain
their actual original generation provenance and are not regenerated by this change.

## Changes

- Added [FOUR_VIEW.md](../../production/creature-pipeline/FOUR_VIEW.md): preparation,
  anatomical orientation, consistency review, missing-view generation, website/API
  mapping, model comparison, texture distinction, records and invalidation.
- Updated [the main handbook](../../production/creature-pipeline/README.md), Meshy
  procedure, acceptance matrix and all five character briefs. The handbook now has
  eight manuals and nine record templates. Open anatomical counts remain proposals.
- Added [view-set.json](../../production/creature-pipeline/templates/view-set.json)
  and reference fields in candidate/generation/review records. All input files,
  provenance, hashes, review and readiness fields remain unfilled.
- Updated the production skill, project instructions and older Meshy guide's current
  route banner so future tasks use four views for new geometry.
- Extended the read-only documentation validator to check four unique ordered slots,
  anatomical labels, absence of invented inputs/approvals and the four-view default.

Meshy can infer missing views, but those views require the same actual consistency
review as other new references. Side mirroring, mixed poses, hidden automatic
completion and silent single-image fallback are excluded from the default route.
Geometry-only results receive clay/neutral review first; texture checks remain
NOT_RUN until the separately authorized texture result exists.

The manuals distinguish the website's described base-color-only multi-view texture
release from API PBR options. Actual account features, costs, map outputs and
improved model accuracy have not been tested here. No images/models generated,
private files uploaded, credits spent, Blender/Unreal edits, installations or new
art approvals occurred. Existing lighting and color choices remain in force.
